# قیمت‌یار

یک ابزار ساده برای تحقیق قیمت بازار: کاربر نام دقیق محصول را می‌نویسد، قیمت‌یار
محصولات مشابه را در ترب، دیجی‌کالا و باسلام پیدا می‌کند و یک بازه مناسب فروش
پیشنهاد می‌دهد. تجربه قیمت‌گذاری و برچسب‌های «فروش سریع / قیمت منصفانه / فروش
صبورانه» از Price Guidance مرکاری الهام گرفته شده‌اند.

## خروجی فعلی

- رابط فارسی RTL و متمرکز بر یک ورودی: نام محصول
- جمع‌آوری هم‌زمان قیمت از ترب، دیجی‌کالا و باسلام
- یکسان‌سازی واحد پول همه منابع به تومان
- سنجش شباهت عنوان و کنترل مدل، ظرفیت، وزن و تعداد بسته
- حذف قیمت‌های پرت با IQR و محاسبه P25/P50/P75
- بازه بازار، قیمت پیشنهادی، وضعیت سرعت فروش و امتیاز اطمینان
- نمایش محصولات مقایسه‌شده همراه لینک منبع
- کش ده‌دقیقه‌ای، timeout، retry محدود و ادامه تحلیل در صورت قطع یک منبع
- ورود غرفه‌دار با OAuth باسلام، نشست امضاشده و جداسازی داده هر غرفه
- داشبورد ساده محصولات با برآورد بازار و بازه قابل‌ویرایش توسط غرفه‌دار
- نوسازی خودکار برآوردها هر شش ساعت با refresh امن توکن
- ثبت تاریخچه تغییرات، endpoint اجرای زمان‌بندی‌شده و وب‌هوک اشتراک App Store
- حالت نمایشی بدون credential برای ارزیابی فوری محصول

## روش محاسبه

برای هر جست‌وجو حداکثر یک صفحه از هر بازار خوانده می‌شود. نتایج با شباهت عنوان
فیلتر می‌شوند و وجود عددهای مدل، وزن یا ظرفیت اهمیت بیشتری دارد. بعد از حذف
outlierها با حصار `1.5 × IQR`:

- `P25`: قیمت رقابتی برای فروش سریع‌تر
- `P50`: قیمت پیشنهادی منصفانه
- `P75`: قیمت بالاتر برای فروش صبورانه

این داده‌ها قیمت فعلی آگهی/فروش هستند، نه داده تراکنش قطعی. نوع، اصالت، وضعیت،
گارانتی، وزن و تعداد بسته می‌توانند نتیجه را تغییر دهند.

### ملاحظات منابع

اتصال باسلام از Search API مستندشده آن استفاده می‌کند. اتصال‌های ترب و
دیجی‌کالا از پاسخ JSON عمومی storefront استفاده می‌کنند و API شریک رسمی محسوب
نمی‌شوند؛ قرارداد آن‌ها ممکن است تغییر کند. پیش از استفاده تجاری، شرایط استفاده
و مجوز گردآوری داده هر سرویس را بررسی کنید. قیمت‌یار درخواست‌ها را محدود و
نتیجه‌های یکسان را ده دقیقه cache می‌کند.

به‌صورت پیش‌فرض درخواست‌های بازار متغیرهای سیستمی `HTTP_PROXY`، `HTTPS_PROXY`
و `ALL_PROXY` را نادیده می‌گیرند تا پراکسی SOCKS دسکتاپ باعث خطای `socksio`
نشود. فقط اگر سرور واقعاً برای اینترنت به پراکسی نیاز دارد مقدار زیر را تغییر
دهید:

```dotenv
MARKETPLACE_TRUST_ENV=true
```

## اجرای محلی

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
set -a
source .env
set +a
uvicorn app.main:app --reload
```

سپس `http://localhost:8000` را باز کنید. پایگاه داده SQLite در `data/nerkhban.db` ساخته و داده نمونه اضافه می‌شود.

تحلیل قیمت از endpoint زیر نیز قابل استفاده است:

```http
POST /api/market/analyze
Content-Type: application/json

{"product_name": "گوشی سامسونگ A55 ظرفیت 256 گیگ"}
```

لینک نتیجه را می‌توان با پارامتر `q` به اشتراک گذاشت:

```text
https://YOUR_DOMAIN/?q=گوشی سامسونگ A55 ظرفیت 256 گیگ
```

اجرای تست:

```bash
pytest
```

## اتصال به باسلام

جست‌وجوی عمومی قیمت در هر سه بازار بدون OAuth و بدون
`BASALAM_CLIENT_ID/BASALAM_CLIENT_SECRET` کار می‌کند. موارد زیر فقط زمانی لازم
است که بخواهید غرفه کاربر را متصل و برای محصولاتش راهنمای قیمت بسازید.

در پنل توسعه‌دهندگان باسلام یک App عمومی بسازید و redirect URI را برابر این مقدار قرار دهید:

```text
https://YOUR_DOMAIN/auth/basalam/callback
```

دو scope فقط‌خواندنی لازم:

```text
vendor.profile.read vendor.product.read
```

سپس متغیرهای `BASALAM_CLIENT_ID`، `BASALAM_CLIENT_SECRET`، `BASALAM_REDIRECT_URI` و یک `APP_SECRET` تصادفی را تنظیم و `DEMO_MODE=false` کنید.

پس از اتصال، غرفه‌دار در `/merchant` محصولات، قیمت فعلی، قیمت پیشنهادی و بازه
بازار را می‌بیند. بازه حداقل و حداکثر را می‌تواند برای هر محصول شخصی‌سازی یا
به مقدار محاسبه‌شده بازنشانی کند. قیمت زنده محصول در باسلام تغییر داده نمی‌شود؛
این قابلیت فقط راهنمای قیمت است.

## نوسازی خودکار برآوردها

سرویس `scheduler` در Compose حساب‌های موعدرسیده را هر شش ساعت بررسی می‌کند.
این فاصله و سقف تعداد محصولاتی که در هر همگام‌سازی تحلیل می‌شوند قابل تنظیم‌اند:

```dotenv
MERCHANT_SYNC_HOURS=6
MERCHANT_PRODUCT_LIMIT=50
```

برای اجرای دستی همان job از داخل سرور:

```bash
curl -X POST http://app:8000/internal/merchant-sync \
  -H "X-Cron-Secret: YOUR_CRON_SECRET"
```

در حالت Compose معمولاً اجرای دستی لازم نیست. مقدار `CRON_SECRET` باید تصادفی،
طولانی و در سرویس app و scheduler یکسان باشد.

## مسیر محصول تا نسخه تجاری

MVP فعلی یک vertical slice است. برای رسیدن به مدل ML شبیه مرکاری:

1. ابتدا از search باسلام comparableها را با category، وزن/واحد، ویژگی‌ها و شباهت متنی فیلتر کنید.
2. outcome واقعی (فروش، زمان تا فروش، بازدید، افزودن به سبد) را روزانه ذخیره کنید.
3. baseline را با LightGBM quantile regression برای P25/P50/P75 بسازید؛ متن فارسی و تصویر را بعد از اثبات baseline اضافه کنید.
4. ارزیابی را با خطای قیمت، زمان تا فروش، GMV و نرخ override فروشنده انجام دهید.
5. تغییر خودکار را ابتدا فقط برای cohort داوطلب و با audit/rollback منتشر کنید.

قیمت پیشنهادی تضمین فروش نیست و باید همیشه به‌عنوان راهنما، همراه با توضیح و امکان override نمایش داده شود.

## استقرار production

فایل‌های `compose.production.yml`، `deploy/Caddyfile` و
`.env.production.example` برای استقرار روی VPS آماده‌اند. Caddy گواهی HTTPS را
خودکار دریافت و تمدید می‌کند و volumeهای Docker پایگاه داده و گواهی‌ها را بین
نسخه‌ها حفظ می‌کنند.

```bash
cp .env.production.example .env.production
# دامنه و secretها را در فایل بالا تنظیم کنید.
docker compose -f compose.production.yml --env-file .env.production up -d --build
docker compose -f compose.production.yml ps
curl https://YOUR_DOMAIN/health
```

برای مشاهده لاگ‌ها:

```bash
docker compose -f compose.production.yml logs -f --tail=100
```

برای دامنه `qeimatyar.ir` مقدار redirect URI را دقیقاً
`https://qeimatyar.ir/auth/basalam/callback` بگذارید و همان آدرس را در پنل
توسعه‌دهندگان باسلام نیز ثبت کنید. بعد از بالا آمدن نسخه جدید، `/login` را باز
و اتصال را ابتدا با یک غرفه آزمایشی بررسی کنید.
